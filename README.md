# 🌌 Wallpapers — Ultra HD & 4K Wallpaper Gallery

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)
[![Repository](https://img.shields.io/badge/GitHub-saurabhdhull1%2Fwallpapers-indigo.svg)](https://github.com/saurabhdhull1/wallpapers)
[![Live Demo](https://img.shields.io/badge/Live%20Demo-GitHub%20Pages-emerald.svg)](https://saurabhdhull1.github.io/wallpapers/)

A modern, high-performance, glassmorphic web application for browsing, searching, and directly downloading high-resolution (4K, 8K, 1080p) wallpapers. Built with Vue 3, Tailwind CSS, Lucide Icons, and direct blob downloading engine.

**🌐 Live Demo:** [https://saurabhdhull1.github.io/wallpapers/](https://saurabhdhull1.github.io/wallpapers/)  
**📁 Repository:** [https://github.com/saurabhdhull1/wallpapers](https://github.com/saurabhdhull1/wallpapers)

---

## ✨ Features & Highlights

- ⚡ **Direct Image Downloads**: One-click download engine that forces direct file downloads to your device without opening images in new tabs.
- 🎨 **Modern Liquid Glass UI**: Dark & Light mode support, smooth backdrop blurs, glow effects, and responsive masonry card layouts.
- 🔍 **Realtime Search & Tags**: Instant filter by name, resolution, or `#tags` (e.g. `@nord`, `@minimal`, `@anime`, `@cyberpunk`).
- 🖥️ **Device Resolution Filtering**: Filter wallpapers by Desktop (16:9 / 21:9), Mobile (9:16), or 4K UHD resolutions.
- 🖼️ **Interactive Lightbox Modal**: High-res preview with zoom in/out, technical metadata breakdown (resolution, aspect ratio, file size), keyboard navigation (`←` / `→` / `Esc`), and link copy.
- ❤️ **Favorites Collection**: Bookmark favorite wallpapers locally in your browser.

---

## 🛠️ Tech Stack

- **Framework**: [Vue.js 3](https://vuejs.org/) (Composition API)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide Icons](https://lucide.dev/)
- **Database**: JSON (`wallpapers_database.json`)

---

## 🚀 Development & Usage

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/saurabhdhull1/wallpapers.git
   cd wallpapers
   ```

2. **Run Locally**:
   Simply open `index.html` in your web browser (or serve with Live Server / `python -m http.server`).
